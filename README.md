# 📱 ListContact

Una aplicación Android desarrollada con Kotlin que consume una API REST para gestionar una agenda de contactos. Permite ver, crear, editar y eliminar personas, así como agregar correos electrónicos y teléfonos asociados a cada una.

---

## 🚀 Características principales

- 🔎 Listado completo de contactos desde una API externa.
- ➕ Agregar personas con sus datos personales.
- ✏️ Editar información de contactos.
- ❌ Eliminar contactos.
- 📞 Agregar múltiples teléfonos por contacto.
- 📧 Agregar múltiples correos por contacto.
- 🌐 Integra Retrofit para realizar solicitudes HTTP.
- 🧠 Uso de ViewModel para gestión de estado y separación de lógica de UI.
- 🧩 Arquitectura limpia con Repository pattern.

---

## 🛠️ Tecnologías usadas

- Kotlin
- Android Jetpack (ViewModel, LiveData)
- Retrofit2
- Gson
- RecyclerView
- API externa

---

## ⚙️ Permisos requeridos

- `INTERNET` – para realizar solicitudes a la API REST.
